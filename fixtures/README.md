# Test Fixtures

All files here are synthetic test and conformance inputs. They contain no
customer, production, credential, or live-environment data.

- `contracts/`: versioned positive and fail-closed cross-language vectors;
- `audit/`: disposable migration-review evidence;
- `console/`: read-only UI and reconciliation examples;
- `knowledge/`: synthetic local-knowledge indexing examples;
- `project-state/`: fictional project inspection examples, including a bounded
  legacy compatibility shape;
- `release/`: source-only release-planning examples.

Fixture presence proves only behavior covered by corresponding tests. It does
not grant authority, enable a route, select a production target, or establish
support.
